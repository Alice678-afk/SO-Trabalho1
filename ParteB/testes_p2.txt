TESTES - Pessoa 2 (interface e verificação)
Formato: comando -> esperado | obtido | OK/ERRO

== 1. Leitura de opções (getopts) ==
Explicação: o getopts lê as opções uma a uma e o case guarda as escolhas em variáveis.
./vp_p2.sh -p                 -> modo=p, bd=/tmp/.pdb, logger=0 | obtido: ...
./vp_p2.sh -v -f bd_teste -s  -> modo=v, bd=bd_teste, logger=1 | obtido: ...

== 2. Erros e mensagem de uso ==
Explicação: opções inválidas chamam a função uso(), que mostra a ajuda e termina com exit 1.
./vp_p2.sh -x                 -> erro + uso, script pára | obtido: ...
./vp_p2.sh -f                 -> erro (falta o valor) + uso | obtido: ...
./vp_p2.sh -p -v              -> erro (opções em conflito) + uso | obtido: ...
./vp_p2.sh -v -p              -> o mesmo (a ordem não interessa) | obtido: ...

== 3. Modo por defeito e BD em falta ==
Explicação: sem -p nem -v o modo é verificação; em verificação, a BD tem de existir.
./vp_p2.sh -v -f nao_existe   -> erro "base de dados não encontrada" + uso | obtido: ...
./vp_p2.sh -f nao_existe      -> o mesmo (modo por defeito = v) | obtido: ...
./vp_p2.sh -p                 -> NÃO dá erro de BD (a BD ainda vai ser criada) | obtido: ...

== 4. Ficheiros apagados ==
Explicação: para cada linha da BD, se o caminho já não existe, é APAGADO.
(bd_teste tem /tmp/a.txt e /tmp/b.txt; apagar /tmp/a.txt antes)
./vp_p2.sh -v -f bd_teste     -> a.txt e b.txt APAGADOS, Apagados: 2 | obtido: ...
touch /tmp/a.txt + repetir    -> só b.txt APAGADO, Apagados: 1 | obtido: ...

== 5. Ficheiros modificados (conteúdo) ==
Explicação: calcula o SHA-256 atual e compara com o da BD; se for diferente, MODIFICADO.
./vp_p2.sh -v -f bd_teste     -> a.txt MODIFICADO (hash inventado na BD) | obtido: ...
(pôr na BD o hash real do a.txt) -> a.txt NÃO aparece, Modificados: 0 | obtido: ...
echo "outra coisa" > /tmp/a.txt + repetir -> a.txt MODIFICADO outra vez | obtido: ...

== 6. Metadados atuais (stat) ==
Explicação: o stat lê dono, grupo, tamanho, permissões e data de cada ficheiro.
(com o echo de teste) -> user, grupo, 4, 664, data em segundos | obtido: ...

== 7. Várias alterações numa mensagem (a fazer) ==
Explicação: cada campo diferente acrescenta o seu nome a "alteracoes"; no fim uma só mensagem.
./vp_p2.sh -v -f bd_teste     -> a.txt MODIFICADO (Conteúdo Tamanho), Modificados: 1 | obtido: ...
